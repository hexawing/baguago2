# 八卦围棋 Demo（baguaGo）

一个把传统围棋与《易经》八卦结合的实验性围棋变体，纯前端、零依赖，单个 `index.html` 双击即用。

> 文化背景参考：[知乎专栏《八卦围棋》](https://zhuanlan.zhihu.com/p/2011132692192837704)（本项目棋规为独立设计，仅借其“八卦入棋”的创意）。

---

## ✨ 特性

- **单文件运行**：仅一个 `index.html`，用 Canvas 绘制棋盘，无需后端、构建工具或联网。
- **八卦变体规则**：棋盘上随机生成 8 个卦点（乾兑离震巽坎艮坤），各自带有不同属性，改写传统围棋的连子、气与计分方式。
- **多种棋盘**：支持 9 路 / 13 路 / 19 路，几何参数随路数自适应缩放。
- **人机 / 双人**：可双人手动对弈，也可与内置 CPU AI 对战（你执黑或执白）。
- **AI 难度**：简单 / 普通 / 困难 三档（通过随机扰动与战术权重调节强弱）。
- **贴目可调**：贴目做成下拉选项，默认随棋盘路数给出（9 路 4.5 / 13 路 5.5 / 19 路 6.5），可手动覆盖。
- **棋谱辅助**：可勾选“显示着法序号”像模谱一样标注每一手；最近一手始终以小圆环标记。

## 📖 棋规说明（本 Demo 实现）

### 1. 八个随机卦点

每局开始，在棋盘上随机生成 8 个卦点，分别对应八卦：**乾 ☰、兑 ☱、离 ☲、震 ☳、巽 ☴、坎 ☵、艮 ☶、坤 ☷**。

每个卦点有三个属性：

| 属性 | 含义 |
| --- | --- |
| `playable`（可落子 / 恒为空） | 乾、兑、离、震 **恒为空**，不可落子；巽、坎、艮、坤 **可落子**。 |
| `diagonalChi`（斜角气） | 乾、兑、巽、坎 具有“通气”特性，斜线方向也算作连接与气。 |
| `scoreMod`（福地 / 咒地） | `+1` 为私有（福地，占之加分）；`-1` 为公有（咒地，占之减分）。 |

> 视觉上：恒为空的点画为空心圆；具有“通气”的点额外画 `X` 斜线；所有卦点都画有四角“炮位”符号（私有线粗、公有线细）。

### 2. 斜向连接（通气）

普通围棋只认上下左右四邻。本变体中，若相邻点为“通气”卦点（或当前点本身通气），则**斜对角方向也视为同色棋块的连接与“气”**。这会影响：

- 棋块死活（提子 / 打吃判定）；
- 终局时领地的归属（斜向通气会“打通”空间边界）。

### 3. 计分

终局（双方连续停一手 Pass）后按以下方式结算：

```
总分 = 占领的领地 + 提子数 + 贴目(komi)
     + 落在卦点上的加减分（福地 +1 / 咒地 -1）
     + 领地中卦点的加减分（福地 +1 / 咒地 -1）
```

白方额外加上设定的贴目。默认：19 路 6.5、13 路 5.5、9 路 4.5（可在下拉框调整）。

### 4. 其他规则

- **吃子 / 提子**：与围棋一致（含斜向连通后的死活判定）。
- **打劫（Ko）**：实现了基本打劫禁着点。
- **停一手（Pass）**：双方连续 Pass 即终局计分。

## 🕹️ 操作说明

右侧「对战设置」面板：

| 控件 | 说明 |
| --- | --- |
| 棋盘 | 选择 9 / 13 / 19 路。 |
| 模式 | 双人对战 / 人机（你执黑）/ 人机（你执白）。 |
| 难度 | 简单 / 普通 / 困难。 |
| 贴目 | 选择白方贴目（默认按路数给出，可覆盖）。 |
| 显示着法序号 | 勾选后棋子中央显示落子手数（棋谱样式）。 |

- **落子**：鼠标移动到交叉点会出现半透明预览，单击落子。
- **最近一手**：始终以棋子上的小圆环标记。
- **开局后**：模式 / 棋盘 / 难度 / 贴目会被锁定，避免对局中途被改动；点「新对局」或终局后可重新设置。

## 🧠 CPU AI 说明

AI 采用轻量级启发式评估（参考经典贪心 / 局部战术型围棋 AI 思路，并适配八卦规则）：

- 优先吃子；制造对方打吃、解救自身打吃；
- 避免自陷打吃、避免填自己的眼；
- 不执着于卦点（除非能吃子或战术必要）；
- 难度通过随机扰动比例调节强弱。

> 注：这是启发式 / 战术型 AI，并非 AlphaGo 式的 MCTS + 神经网络，属于“能正常对弈”的水平。
